# Cardiovascular Disease Prediction Using Machine Learning

## 📌 Project Overview

This project focuses on predicting cardiovascular disease using Machine Learning techniques.

The project uses patient health information such as age, gender, height, weight, blood pressure, cholesterol, glucose levels, smoking habits, alcohol consumption, and physical activity to predict whether cardiovascular disease is present.

The main objective is to analyze health-related data and build a machine learning model for cardiovascular disease classification.

## 📊 Dataset Information

- **Dataset Name:** Cardiovascular Disease Dataset
- **Source:** Kaggle
- **Total Records:** 70,000
- **Input Features:** 11
- **Target Variable:** cardio
- **Problem Type:** Binary Classification
- **File Format:** CSV

### Dataset Features

| Column | Description |
|---|---|
| age | Age of the patient (days) |
| gender | Gender category |
| height | Height in cm |
| weight | Weight in kg |
| ap_hi | Systolic blood pressure |
| ap_lo | Diastolic blood pressure |
| cholesterol | Cholesterol level |
| gluc | Glucose level |
| smoke | Smoking status |
| alco | Alcohol consumption |
| active | Physical activity |
| cardio | Target variable |

### Target Variable

- `0` – Cardiovascular disease not recorded.
- `1` – Cardiovascular disease recorded.
